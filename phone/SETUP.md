# 안드로이드 스튜디오 설치 — 윈도우 11

이 폴더에 휴대폰 앱이 들어갑니다. 그 전에 빌드할 도구를 깝니다.

> ※ 화면의 글자와 버전 번호는 시간이 지나면 바뀝니다. 여기 적은 것은
> **무엇을 고르고 무엇을 건너뛰는가** 입니다. 마법사가 다른 말을 하면
> 마법사를 따르시고, 아래의 '건너뛸 것' 만 지키세요.

| | |

영문이라 그대로 두면 됩니다.

## 1. 내려받기

<https://developer.android.com/studio>

윈도우용 `.exe` 를 받습니다. 1 GB 안팎입니다.

## 2. 설치

기본값으로 넘어가되 **한 가지만 끕니다.**

```
[ ] Android Virtual Device      ← 체크를 풉니다
```

★ **에뮬레이터는 안 씁니다** ★
우리는 진짜 휴대폰에 바로 올려서 시험합니다. 에뮬레이터는 몇 GB 를
더 먹고, 가상화(Hyper-V / WHPX)가 안 켜져 있으면 거기서 한나절을
씁니다. 그리고 우리 앱은 **로봇과 같은 공유기에 붙어야** 하는데,
에뮬레이터의 네트워크는 그게 번거롭습니다. 처음부터 진짜 폰이 낫습니다.

## 3. 첫 실행 — SDK 받기

마법사가 뜹니다. `Standard` 로 진행하면 됩니다. 이때 받는 것:

- **Android SDK Platform** — 최신 안정 버전 하나
- **Android SDK Build-Tools**
- **Android SDK Platform-Tools** — `adb` 가 여기 들어 있습니다

여기서 또 몇 GB 를 받습니다. 시간이 걸립니다.

## 4. 휴대폰 쪽 — 개발자 옵션 켜기

삼성 기준입니다.

```
설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호를 일곱 번 누름
설정 → 개발자 옵션 → USB 디버깅  켜기
```

### ⚠ 'USB 디버깅' 스위치가 회색이라 안 켜진다면

삼성의 **보안 위험 자동 차단(Auto Blocker)** 이 막고 있는 것입니다.
안드로이드 14(One UI 6) 부터 기본으로 켜져 있고, **USB 로 들어오는 명령**을
막는 것이 그 기능의 일입니다. 우리가 하려는 것이 정확히 그것이라
정직하게 걸린 셈입니다.

```
설정 → 보안 및 개인정보 보호 → 보안 위험 자동 차단 → 끄기
그다음 개발자 옵션으로 돌아가면 스위치가 살아 있습니다
```

★ **무선 디버깅으로 피할 수 없습니다** ★
자동 차단은 무선 디버깅도 같이 회색으로 만듭니다. 둘 다 이걸 꺼야
열립니다.

※ 켜져 있으면 안 되는 물건이 아닙니다. 남이 내 폰에 케이블을 꽂아
  명령을 넣는 것을 막아주는 기능입니다. **시연이 끝나면 다시 켜세요.**
  개발할 때만 꺼두는 것이 맞습니다.

※ 회사·학교에서 관리하는 폰(MDM)이면 자동 차단과 무관하게 막혀 있을 수
  있습니다. 그때는 우회하지 말고 관리 부서에 문의해야 합니다.

### 무선으로 붙이면 더 편합니다

USB 케이블 없이 됩니다. 폰과 PC 가 같은 공유기에 있으면 되는데,
우리는 **어차피 로봇 때문에 같은 공유기에 있습니다.**

```
휴대폰:  개발자 옵션 → 무선 디버깅 → 켜기 → '페어링 코드로 기기 페어링'
스튜디오: 기기 목록 → Pair Devices Using Wi-Fi → 코드 입력
```

### ⚠ 만들고 나서 반드시 손볼 것 하나

안드로이드는 **암호화 안 된 http 통신을 기본으로 막습니다** (API 28+).
그런데 로봇은 `http://192.168.0.51:9991` — 평문입니다. 그대로 두면
연결이 조용히 실패합니다.

같은 공유기 안의 로봇에게만 열어주는 것이 맞습니다. 전체를 여는 것이
아니라 **그 주소만** 허용하는 설정을 넣습니다 (코드 쓸 때 같이 합니다).

## ★ 이 앱이 무엇을 할 것인가 ★

거의 다 이미 만들어져 있습니다. 앱에서 **새로 쓰는 네이티브 코드는
`sig.py` 가 하는 일 하나뿐**입니다.

```
화면 · 안내 로직 · 조종판 · 메뉴      지금 것을 그대로 (WebView)
WebRTC · 데이터채널 · 오디오          브라우저가 합니다
시그널링 두 번의 HTTP                 ★ 여기만 Kotlin ★
```

왜 그 하나만 네이티브인지는 `web_probe.py` 와 `sig.py` 에 적혀 있습니다.
짧게는 — 로봇이 CORS 헤더를 안 주고, 쓰는 암호(AES-ECB · RSA PKCS1v1.5)가
브라우저 표준에 없습니다.

그리고 그 하나가 맞는지는 `sig_test.py` 가 **로봇 없이** 채점합니다.
Kotlin 으로 옮긴 뒤에도 같은 가짜 로봇에 붙여보면 됩니다.
