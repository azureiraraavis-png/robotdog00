======================================================================
 전방 라이트 후보 시험
======================================================================
 ★ 코드 0 을 믿지 않습니다 ★
   SwitchAvoidMode 가 코드 0 을 주면서 아무 일도 안 하는 걸 봤습니다.
   눈으로 본 것만 결과로 적습니다.

 [1005] 색 켜기 (흰색)              코드 100
 [1005] 색 켜기 (빨강)              코드 100
 [1005] 색 켜기 (시간 없이)           코드 100
 [1004] 밝기 올리기                 코드 0
          기대: 가장 밝게
          → 안 보였습니다
 [1004] 밝기 올리기 (data)          코드 0
          기대: 값 모양이 다를 수 있어 한 번 더
          → 안 보였습니다
 [1006] 밝기 읽기                  코드 0
          기대: 지금 밝기 값을 돌려주는지
          → 안 보였습니다
 [1005] 끄기                     코드 100

======================================================================
 정리
======================================================================
 코드는 0 인데 아무것도 안 보였습니다.
 회피 모드 때와 같은 상황입니다 — 받아들이기는 하나 동작은 안 합니다.
 라이트는 포인터로 못 씁니다. 몸통 기울이기만으로 가야 합니다.
