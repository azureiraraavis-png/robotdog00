========================================================================
 1단계 — VUI 가 어떤 api_id 를 받아주는가
========================================================================
 모르는 번호는 코드 100 으로 거부합니다. 그래서 0 이 오면 실재하는 명령입니다.

   1001   코드 100
   1002   코드 0  ← 살아 있음
   1003   코드 100
   1004   코드 0  ← 살아 있음
   1005   코드 100
   1006   코드 0  ← 살아 있음
   1007   코드 100
   1008   응답 없음 (3초)   ★ 무응답 명령일 수 있습니다 ★
   1009   응답 없음 (3초)   ★ 무응답 명령일 수 있습니다 ★
   1010   코드 0  ← 살아 있음
   1011   코드 100
   1012   응답 없음 (3초)   ★ 무응답 명령일 수 있습니다 ★

 ★ 응답이 없던 번호들 — 여기를 눈여겨보세요 ★
     1008, 1009, 1012
   무응답은 '아무 일도 안 했다' 가 아닙니다. 라이브러리에도
   무응답 명령이 있습니다 (회피 서비스의 MOVE 옆에 no-reply).
   ★ 이 번호를 보낼 때 로봇에게 무슨 일이 있었는지 떠올려 보세요 ★
     불이 켜졌거나, 소리가 났거나, 무언가 달라졌습니까?

========================================================================
 2단계 — 살아 있는 번호의 응답 전문
========================================================================
 ★ 여기가 핵심입니다 ★  응답 안의 항목 이름이 곧 설명서입니다.

   [1002]
     {"type": "res", "topic": "rt/api/vui/response", "data": {"header": {"identity": {"api_id": 1002, "id": 1773148536}, "status": {"code": 0}}, "data": "{\"enable\":1}"}}
     항목 이름: enable

   [1004]
     {"type": "res", "topic": "rt/api/vui/response", "data": {"header": {"identity": {"api_id": 1004, "id": 1773149478}, "status": {"code": 0}}, "data": "{\"volume\":5}"}}
     항목 이름: volume

   [1006]
     {"type": "res", "topic": "rt/api/vui/response", "data": {"header": {"identity": {"api_id": 1006, "id": 1773149593}, "status": {"code": 0}}, "data": "{\"brightness\":0}"}}
     항목 이름: brightness

   [1010]
     {"type": "res", "topic": "rt/api/vui/response", "data": {"header": {"identity": {"api_id": 1010, "id": 1773157028}, "status": {"code": 0}}, "data": "{\"enable\":0}"}}
     항목 이름: enable

 ★ 빛과 관련되어 보이는 항목: brightness

========================================================================
 3단계 — 밝기를 올려 봅니다
========================================================================
 ★ 짐작이 아니라 규칙으로 갑니다 ★
   1002/1004/1006/1010 이 값을 돌려주고, 1001/1003/1005/1011 은
   빈 파라미터를 거부합니다. 홀수가 설정, 짝수가 조회입니다.
   그러니 1006(GET brightness)의 짝은 1005(SET brightness) 입니다.

 그리고 **눈이 아니라 로봇에게 물어서** 확인합니다.
   올린 뒤 다시 읽어서 값이 실제로 바뀌었는지 봅니다.

   brightness: 지금 0  (설정 1005 / 조회 1006)
     brightness=10  보냄 → 코드 0,  다시 읽으니 10

 ★ 값이 실제로 바뀌었습니다 — api_id 1005, {"brightness": N} ★

   → ★ 켜졌습니다 ★
   (원래 값 0 로 되돌렸습니다)

========================================================================
 정리
========================================================================
 ★ 전방 라이트를 코드로 켤 수 있습니다 ★

     conn.datachannel.pub_sub.publish_request_new(
         RTC_TOPIC["VUI"],
         {"api_id": 1005, "parameter": {"brightness": 0~10}})

 이제 음성 명령에 붙일 수 있습니다. 그리고 복도에서 두 가지만 더 보세요.
   1. 실내조명이 켜진 낮에도 보이는가
   2. 앞을 '비추는' 가, 얼굴처럼 '빛나기만' 하는가
      후자면 문을 가리키는 용도로는 못 씁니다
